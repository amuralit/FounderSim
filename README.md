# FounderSim

**From one sentence to investor-ready in minutes.**

5 AI agents research your market, design your product, write the code, and deploy it — while you watch and steer.

## Output

1. 🌐 Live deployed product on Vercel
2. 📊 Pitch deck with real competitor data
3. 🔍 Market research with verified pricing + source URLs
4. 🏗️ Architecture docs with Mermaid + SQL
5. 📜 Decision log of every debate and approval

## Stack

Vercel AI SDK 6 · v0 Platform API · Gemini 3.1 Pro · Google Search · URL Context · Nano Banana Pro · Supabase · Next.js 15

## Setup

```bash
cp .env.example .env.local  # Fill keys
pnpm install && pnpm dev
```
